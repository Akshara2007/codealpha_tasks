CodeAlpha Internship Tasks



This repository contains three projects completed as part of the CodeAlpha internship program.



Task 1: E-commerce Store



A Django-based e-commerce web application featuring product listings, product details, a shopping cart, user authentication, and checkout functionality.



Technologies: Python, Django, HTML, CSS, JavaScript, SQLite



Task 2: ConnectHub – Social Media Platform



A Django-based social media application that allows users to create posts, like and comment on posts, manage profiles, and follow other users.



Technologies: Python, Django, HTML, CSS, SQLite



Task 3: TaskFlow – Project Management Tool



A Django-based project management application for creating projects, managing tasks, assigning tasks to users, setting due dates, updating task status, and tracking project progress.



Technologies: Python, Django, HTML, CSS, SQLite



Repository Structure



EcommerceStore/ – Task 1



SocialMedia/ – Task 2



ProjectManagement/ – Task 3



Running the Projects



Each project has its own Django configuration and manage.py file. Open the relevant project folder in a terminal, install Django, apply migrations, and run the development server.



python -m pip install django

python manage.py migrate

python manage.py runserver
