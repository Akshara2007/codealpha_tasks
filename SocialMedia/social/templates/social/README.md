# CodeAlpha Social Media Platform

A mini social media platform built using Django, Python, HTML, and CSS.

## Features
- User registration and login
- Create and view posts
- Like and unlike posts
- Add comments to posts
- Follow and unfollow users
- View user profiles
- Edit profile bio and profile picture URL

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- Git and GitHub

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Akshara2007/CodeAlpha_SocialMedia.git
   ```

2. Open the project folder:
   ```bash
   cd CodeAlpha_SocialMedia
   ```

3. Install Django:
   ```bash
   python -m pip install django
   ```

4. Apply database migrations:
   ```bash
   python manage.py migrate
   ```

5. Start the development server:
   ```bash
   python manage.py runserver
   ```

6. Open `http://127.0.0.1:8000/` in your browser.
