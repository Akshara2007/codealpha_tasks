# CodeAlpha E-commerce Store

A basic e-commerce web application developed using Python and Django.

## Features
- Product listing with images and prices
- Product detail pages
- Product search
- Shopping cart and subtotal calculation
- User registration, login, and logout
- Checkout and order processing
- Orders stored in the database
- Automatic stock updates after placing orders
- CSS styling

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Apply migrations using `python manage.py migrate`.
4. Start the server using `python manage.py runserver`.
5. Open `http://127.0.0.1:8000/` in your browser.
